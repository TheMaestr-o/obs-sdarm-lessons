SDARM Lesson Questions — OBS Lower Thirds

A test bench collecting every overlay option we've tried — try each one, compare, add new ones as we find them.
⚠️ Browser ≠ OBS What you see here in a regular browser (Chrome/Safari) isn't a guarantee of the same look inside OBS. OBS renders a Browser Source through its own embedded engine (CEF), which may differ in font versions and spacing. Opening files here is fine for a quick check of text and logic, but always verify the final look by adding the file as a real Browser Source inside OBS itself — that's the only way to see what viewers will actually see.

Plan 1 — Animated Lower Thirds panel works on Mac

control-panel.htmlcontrol panel — text, timing, logo browser-source.htmlthe overlay itself — this is what you add to OBS as a Browser Source
  1. Open both links in two tabs of the same browser
  2. In the panel, switch on the top Main settings toggle — without it, every slot is forced off
  3. Type text into slot 1 (the text fields under the logo) and switch it on — the overlay appears in the other tab
Look: a dark strip, logo on the left, a vertical colored divider line. Fully offline — nothing pulled from the internet.

Plan 3 — infor-r Lower Thirds fully offline

panel.htmlcontrol panel — question text, template, colors result.htmlthe overlay itself — this is what you add to OBS as a Browser Source
  1. Open both links in two tabs of the same browser
  2. In the panel, fill in line 1 (the lesson topic) and line 2 (a letter + the question, e.g. "a. What evidence..."), pick a style, and press Show
  3. The overlay plays its entrance animation once and then holds indefinitely — it does not auto-hide. Press Show again whenever you're ready to advance to the next question
Look: the same design from CodePen mattchestnut/dMrONe that we were asked to use as the reference in the first place, rebuilt as our own CSS (OBS_InforR-Lower/native/) so the entrance animation can hold forever instead of auto-reversing after a couple of seconds. Background is true CSS transparency — no Chroma Key filter needed in OBS, unlike Plans 1/2. The panel only offers three named styles — the other two built-in templates break with a long question (see LOCAL-SETUP.md for the full comparison, and the original lower.html?id=... still works directly by URL if you want to see all 5, auto-hide included).
