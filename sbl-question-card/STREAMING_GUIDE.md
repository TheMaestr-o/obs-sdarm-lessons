# SBL Quiz — Streaming Integration Guide

Полное руководство по интеграции интерактивных плашек вопросов с OBS и Wirecast.

## 1. Быстрый старт

### Что вам нужно:
- **OBS Studio** или **Wirecast** (установлены)
- **SBL Quiz** (этот проект)
- Локальный или удалённый веб-сервер
- **Текстовый редактор** (для быстрого обновления вопросов)

### Откуда берутся вопросы?

Вопросы из текущего урока автоматически парсятся из файла:

```
sbl-quiz/questions.json
```

Вы меняете текст в `questions.json` → сохраняете → плашки на стриме обновляются автоматически каждые 5 секунд.

## 2. Технические основы прозрачности

### Как работает прозрачность для бродкаста?

**HTML-плашка (`streaming.html`):**
- Имеет `background: transparent` в CSS
- OBS/Wirecast видят **только сами элементы** (карточка вопроса, текст, кнопки)
- Всё остальное (чёрный фон HTML страницы) **не видно**

**Видео подложки (если нужны):**
- Экспортируются в **ProRes 4444** (DaVinci Resolve, Final Cut Pro)
- Или в **WebM с альфа-каналом** для OBS
- Или в **PNG** (если статика)

**Без видео подложек:**
- Плашка просто появляется поверх вашего видео в реальном времени
- Полностью готово к использованию

## 3. Интеграция с OBS

### Шаг 1: Добавить источник браузера

```
1. OBS → Сцена → (+) Источник
2. Выберите "Браузер" (Browser Source)
3. Конфиг:
   - Локальный файл: ❌ НЕ включайте (для удалённого сервера)
   - URL: http://localhost:8000/streaming.html
   - Размер: 1920×1080 (или ваше разрешение трансляции)
   - FPS: 30
   - ✓ Галочка "Взаимодействовать" (Interact) — нужна для тестов локально
```

### Шаг 2: Задать размер и позицию

```
Кликните на элемент в сцене → Edit → Resize source
Выберите нужный размер плашки (обычно 900px × 600px на 1920×1080)
```

### Шаг 3: Включить интерактивность для локального управления

```
ПКМ на источнике → "Взаимодействовать" (Interact)
Откроется окно, где можно:
  - Кликать по кнопкам "Next", "Prev", "Reveal"
  - Видеть вопросы в реальном времени
  - Тестировать анимации
```

### Шаг 4: Во время трансляции

```
Обновить вопросы:
  1. Откройте questions.json в любом текстовом редакторе
  2. Измените текст вопроса / ответы
  3. Сохраните файл (Ctrl+S / Cmd+S)
  4. Плашка на стриме обновится в течение 5 секунд автоматически
     (благодаря встроенному скрипту автозагрузки)

Переключение вопросов:
  1. Окно "Interact" OBS остаётся открытым рядом
  2. Кликайте "Next" в окне Interact
  3. Вопрос меняется мгновенно на стриме
```

## 4. Интеграция с Wirecast

### Шаг 1: Добавить источник Web Page

```
Wirecast → Источник (Source) → Web Page
URL: http://localhost:8000/streaming.html
Размер: 1920×1080 (или ваше разрешение)
```

### Шаг 2: Включить прозрачность

```
Wirecast → Select Shot → Properties
✓ Чекбокс "Transparent background" (Прозрачный фон)
```

### Шаг 3: Добавить в Live (вывести в эфир)

```
1. Добавьте Web Page в Master Layers
2. Подготовьте shot в Preview
3. Нажмите кнопку "Go" (или пробел) для перехода в Live
4. Плашка появится поверх вашего видео с прозрачностью
```

### Шаг 4: Управление вопросами

```
В Preview окне (локально):
  - Кликайте по кнопкам
  - Управляйте вопросами в реальном времени
  
На стриме (Live):
  - Зрители видят вопросы с анимацией
  - Вы видите Preview для управления
```

## 5. Обновление вопросов во время трансляции

### Вариант 1: Прямое редактирование JSON (быстро)

```
questions.json (открыт в редакторе)

Было:
"text": "What is the main theme?"

Становится:
"text": "What is your favorite verse?"

Сохраняете → через 5 сек плашка обновляется
```

### Вариант 2: Заменить весь файл

```
1. Скопируйте вопросы из урока в questions.json
2. Убедитесь в правильности JSON (используйте JSONLint.com для проверки)
3. Сохраните
4. Плашка загрузит новые вопросы в течение 5 секунд
```

### Вариант 3: Использовать скрипт для парсинга урока

```
Если урок хранится в формате HTML:
1. Используйте tools/parse-lesson.js (создавайте по необходимости)
2. Скрипт автоматически извлекает вопросы
3. Генерирует questions.json
4. Плашка мгновенно обновляется
```

## 6. Дизайн плашек: адаптация под вашу трансляцию

### Цвета

Откройте `streaming.html` → поиск `:root`:

```css
:root {
  --color-primary: #24426e;      /* Основной цвет */
  --color-text: #ffffff;           /* Текст */
  --color-info: #2196f3;           /* Акцентный цвет */
}
```

Измените на цвета вашего канала:
```css
--color-primary: #e63946;  /* Например, красный */
--color-info: #f77f00;     /* Оранжевый акцент */
```

### Размеры и фонты

```css
.question-text {
  font-size: 2.2rem;       /* Размер текста вопроса */
  font-weight: 600;
}

.option {
  font-size: 1.1rem;       /* Размер текста ответов */
}
```

Увеличьте для лучшей читаемости на трансляции:
```css
.question-text { font-size: 3rem; }
.option { font-size: 1.5rem; }
```

### Анимации

Откройте `streaming.html` → поиск `@keyframes`:

```css
@keyframes slideInUp {
  from { opacity: 0; transform: translateY(50px); }
  to { opacity: 1; transform: translateY(0); }
}
```

Отключите анимацию (если плашка появляется слишком медленно):
```css
.quiz-overlay { animation: none; }
```

Или задайте свою скорость:
```css
.quiz-overlay { animation: slideInUp 0.3s ease; /* быстрее */ }
```

## 7. Типы вопросов и их отображение

### Open Question (Открытый вопрос)
- Текстовое поле для введения ответа
- Красиво смотрится для обсуждений
- **Badge:** "OPEN QUESTION" (фиолетовый)

### Multiple Choice - Single (Один ответ)
- 3-4 кнопки-варианта
- Анимация: появление с задержкой
- **Badge:** "MULTIPLE CHOICE" (голубой)

### Multiple Choice - Multiple (Несколько ответов)
- До 5 кнопок
- Можно выбрать несколько
- **Badge:** "SELECT ALL" (голубой)

### True / False (Верно / Неверно)
- Две больших кнопки рядом
- Контрастные цвета (зелёный/красный на значках)
- **Badge:** "TRUE OR FALSE" (оранжевый)

### Fill the Blank (Заполни пропуск)
- Текстовое поле для одного слова
- Компактный вид
- **Badge:** "FILL THE BLANK" (зелёный)

## 8. Полный рабочий процесс трансляции

### До начала трансляции:

```
1. Запустите локальный сервер:
   python3 -m http.server 8000
   (в папке sbl-quiz)

2. Откройте OBS/Wirecast

3. Добавьте браузер-источник (streaming.html)

4. Протестируйте:
   - Кликните "Next" / "Prev" в окне Interact
   - Проверьте, что плашка появляется с анимацией
   - Убедитесь в прозрачности фона
```

### Во время трансляции:

```
Минута 1: Первый вопрос
  ├─ Плашка появляется с анимацией
  ├─ Зрители видят вопрос и 3-4 варианта
  └─ Вы управляете кликами в окне Interact OBS

Минута 2-3: Обсуждение
  ├─ Зрители отвечают в чате
  └─ Вы ничего не нажимаете (плашка стоит)

Минута 3: Раскрытие ответа
  ├─ Кликните "Reveal" в окне Interact
  └─ На стриме подсвечивается правильный ответ (зелёный/красный)

Минута 4: Следующий вопрос
  ├─ Кликните "Next" в окне Interact
  └─ Плашка с новым вопросом появляется с анимацией
```

### Если нужно срочно поменять вопрос:

```
1. Откройте questions.json в редакторе
2. Измените текст вопроса
3. Сохраните (Ctrl+S)
4. Подождите 5 секунд
5. Плашка на стриме обновится автоматически
```

## 9. Расширенные техники

### Использование Lottie-анимаций вместо CSS

Если нужны сложные анимации (например, конфетти при правильном ответе):

```html
<!-- Добавьте в streaming.html перед </body> -->
<script src="https://unpkg.com/@lottiefiles/lottie-player@latest/dist/lottie-player.js"></script>

<!-- В CSS добавьте -->
.confetti { position: fixed; top: 0; left: 0; pointer-events: none; }
```

Затем в JS:
```javascript
function revealAnswers() {
  // ... ваш код
  // После раскрытия правильного ответа:
  const player = document.createElement('lottie-player');
  player.src = 'https://lottiefiles.com/animation/confetti.json';
  player.play();
  document.body.appendChild(player);
}
```

### Автозапуск вопросов по таймеру

```javascript
// В streaming.html, в конце скрипта:
setInterval(() => {
  // Автоматически переходит на следующий вопрос каждые 30 секунд
  if (confirm('Перейти на следующий вопрос?')) {
    nextQuestion();
  }
}, 30000);
```

### Синхронизация с чатом (для Advanced)

Если вы используете **Streamlabs OBS** с интеграцией чата:

```javascript
// Отправить сообщение в чат при раскрытии ответа
fetch('https://your-streamlabs-endpoint/chat', {
  method: 'POST',
  body: JSON.stringify({
    message: 'Правильный ответ был раскрыт! Проверьте свои ответы.'
  })
});
```

## 10. Устранение неполадок

### Плашка не отображается в OBS

```
1. Проверьте URL в свойствах браузер-источника
2. Убедитесь, что сервер запущен (python3 -m http.server 8000)
3. Откройте URL в обычном браузере: http://localhost:8000/streaming.html
4. Если видно пусто → проверьте Console (F12) на ошибки JavaScript
5. Перезагрузите источник в OBS (ПКМ → Refresh)
```

### Текст не обновляется при изменении questions.json

```
1. Убедитесь, что JSON правильный (используйте JSONLint.com)
2. Файл сохранён в UTF-8 без BOM
3. Подождите 5 секунд (скрипт проверяет каждые 5 сек)
4. Откройте Console (F12) и посмотрите ошибки fetch
```

### Анимация зависает

```
1. Откройте Developer Tools (F12)
2. Проверьте вкладку Performance
3. Если высокое CPU → отключите анимации:
   .quiz-overlay { animation: none !important; }
```

### OBS лагает с браузер-источником

```
1. Уменьшите разрешение плашки: 1280×720 вместо 1920×1080
2. Отключите "FPS" в свойствах источника (или установите 30 вместо 60)
3. Закройте другие источники браузера
4. Используйте аппаратное ускорение (OBS → Tools → GPU Acceleration)
```
